# Darwinbox FDE Take-Home — Build an AI-Powered Data Q&A Web App

Source: `FDE_Assignment_Darwinbox.pdf` (Take-Home Task Brief, Forward Deployed Engineer)

## 1. Overview

Independent exercise — completed on your own, no support available, evaluated in a
follow-up conversation with the panel.

> You are not being tested on your ability to write code by hand. You are being tested on
> how you scope an ambiguous problem, make sound decisions under constraints, and use AI
> tools to go from idea to a working prototype.

## 2. The challenge

Build a small web application where a user can upload one or more CSV/Excel files and ask
analytical questions about the data in plain English — and get back a clear, correct answer.

## 3. Acceptance criteria

1. **Multi-file upload** — the user can upload multiple CSV/Excel files in a single session.
2. **Cross-file analysis** — the app can answer common analytical questions (totals, averages,
   filters, comparisons, trends) across the uploaded files.
3. **Visual insights** — the app renders basic charts or visual summaries where the question
   calls for one.
4. **Delta solutioning on top of what AI does.**

## 4. Constraints & tooling

- Use **open-source AI models**.
- AI coding tools (Claude, ChatGPT, Cursor, Copilot, etc.) are allowed to build, debug, refine.

## 5. Deliverables

- **Working prototype** — a hosted link, or local run instructions with a short demo recording.
- **Source code repository** — a Git repo with the full source and a README covering setup and tech stack.
- **Short write-up** — 1 page max, on your approach, key decisions, and what you'd build next.

## 6. Time expectation

Roughly **4–6 focused hours**. "A smaller, well-thought-through app beats a sprawling,
half-working one."
